## How I build

- **Quality before shipping:** linting, automated tests and a clean build before anything goes live.
- **Security from the start:** input validation, rate limiting and hardened defaults.
- **Built for two languages:** English and Spanish from day one.
- **Ready for production:** backups, smoke tests and scripts that make operations repeatable.
- **Consistent design:** shared design tokens instead of one-off styles.
